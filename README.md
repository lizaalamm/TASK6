# U Devs Car Showroom Management System

A professional React.js application for managing car showroom operations, inventory, suppliers, customers, and applications.

## 🚀 Features

- **Role-Based Access Control** - Admin, Sales, Inventory, and Customer roles
- **Car Inventory Management** - Complete CRUD operations with search, filter, and sort
- **Supplier Management** - Track suppliers and link them to cars
- **Customer Portal** - Browse showroom, apply for cars, track applications
- **Application Management** - Staff can update application statuses
- **Dashboard & Reports** - Real-time KPIs and analytics
- **Responsive Design** - Works on desktop, tablet, and mobile
- **Dark/Light Mode** - Toggle between themes

## 🛠️ Technology Stack

- React.js (Functional Components + Hooks)
- Material UI (Component Library)
- Bootstrap (Grid & Utilities)
- React Router (Navigation)
- LocalStorage (Data Persistence)
- Vite (Build Tool)

## 📦 Installation

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd udevs-car-showroom-management-system

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm build

# Preview production build
npm preview
